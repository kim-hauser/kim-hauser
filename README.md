## 🚦 Featured project: ReadyBoard

[ReadyBoard](https://github.com/kim-hauser/readyboard-fullstack) is a full-stack change readiness app inspired by real-world change management workflows.

Built with React, Spring Boot, and MySQL, it features:

- CRUD operations for change records
- Dashboards organized by status and assignment group
- Ownership, assignment group, and risk filters
- CSV imports with existing-record lookups
- Relational data persistence and REST APIs

What started as a request for a prettier dashboard became a capstone project.
